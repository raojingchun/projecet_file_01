# Web Crawler - First Project

## Project Overview
This is the first practice project for web crawling, designed to demonstrate the basic implementation of a web scraper using Python. The crawler fetches specific data from a target website (e.g., product information, article content) and saves the results to a local file (CSV/JSON).

## Features
- Simple and lightweight web scraping logic
- Extract structured data from HTML elements (using BeautifulSoup)
- Save crawled data to a CSV file for easy analysis
- Basic error handling for network issues and missing elements

## Prerequisites
Before running the crawler, ensure you have the following installed:
- Python 3.8+
- Required Python libraries:
